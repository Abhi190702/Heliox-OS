# Heliox OS v0.11.1 — Adaptive Companion Release

v0.11.1 publishes the complete adaptive multimodal companion feature set developed after v0.9.0. It supersedes the unpublished v0.11.0 build candidate and adds deterministic Windows release packaging.

## Highlights

- **Continuous companion loop** — always-on voice, barge-in, spoken suggestions, risk interruption, browser control, and application control use one coordinated execution path.
- **Adaptive intelligence** — bounded experience learning, temporal memory, strategy evolution, and an optional JEPA-style predictor advise future plans without expanding permission.
- **21 specialists and 156 action types** — the capability-driven mesh reports a concrete provider for every declared action type.
- **Reliable multimodal control** — gaze, 3D hand tracking, gesture workflows, and cursor mode share the camera while temporal verification rejects face-like and single-frame false positives.
- **Guarded neural research** — synthetic BrainFlow and recorded PhysioNet EEGBCI workflows exercise signed, calibrated, consent-bounded intents without claiming verified live brain control.
- **Truthful execution** — persistent sessions, resumable workflows, semantic browser targeting, installed-application resolution, approval continuity, cancellation handling, and result verification reduce false success reports.
- **Moderated plugins and public evidence** — reviewed packages, generated capability/proof/release feeds, citation metadata, `llms.txt`, MCP, and use-case pages make behavior and limits inspectable.
- **Reliable delivery** — first-run Chromium provisioning plus Windows, macOS, and Linux installers are produced from one gated workflow. Windows WiX is fetched with retries and verified against a pinned SHA-256 before MSI creation.
