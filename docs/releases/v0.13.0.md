# Heliox OS v0.13.0 — Verified Autonomy and Runtime Hardening

v0.13.0 consolidates 145 post-0.12 commits into a reliability-focused release. It strengthens terminal-result truthfulness, live configuration, authenticated peer collaboration, multimodal arbitration, daemon lifecycle cleanup, and local performance evidence while preserving Heliox's deterministic permission and approval boundaries.

## Highlights

- **Truthful execution contracts** — Completed work is revalidated against executor results and durable checkpoints. Failed, rejected, skipped, partial, unavailable, and conflict states remain visible rather than being converted into success messages.
- **Transactional live settings** — Supported model, device, calendar, camera, gesture, voice, and peer-mesh settings validate before commit, apply atomically, and roll back when a live runtime rejects the update.
- **Authenticated peer collaboration** — Opt-in LAN peers use authenticated setup, bounded timeouts, constrained delegation, private-network request gates, and the normal collaboration startup and permission path.
- **Coordinated multimodal control** — Voice, gaze, gesture, cursor, approval, and staged neural signals arbitrate shared camera and dialog ownership more reliably. Browser development also reports neural-sidecar status instead of hiding an unavailable sidecar.
- **Bounded runtime resources** — Shutdown quiesces autonomous work, monitors, browser resources, provider CLIs, input services, and collaboration tasks. Heavy local TTS/model inference is isolated from the long-lived daemon and released after an idle window.
- **Measured execution quality** — Heliox records step-budget quality, skips an action only when deterministic evidence already satisfies it, preserves fast local status routes, and publishes a refreshed reproducible software benchmark bundle.

## Reproducible evidence snapshot

- The generated catalog declares **157 action types** across **21 executable specialists** with provider coverage for every declared action. This does not mean every action is available on every host or independently verified.
- The release benchmark measures **26.476 ms median** and **27.999 ms p95** for 100 guarded, steady-state CPU-status requests with **zero model calls**.
- Four real read-only status paths measured **26.556 ms CPU**, **7.261 ms memory**, **6.122 ms disk**, and **60.922 ms system-information** median latency across 50 iterations each.
- The deterministic dispatch regression passed **59/59** fixed cases with **0.022 ms median** routing latency.
- During a real one-second CPU monitor sample, the concurrent heartbeat's maximum interval was **16.575 ms**. This measures scheduler availability, not UI or hardware-input latency.
- The shipped learned-risk model retained its documented 36,000 training and 5,400 temporal-validation sample metadata, passed 5/5 direction invariants, and measured **0.030 ms median** local inference.

## Safety and privacy boundaries

- Authenticated peers do not bypass local permissions, approvals, gateway floors, or verification. Peer availability and network trust still depend on the user's environment.
- A deterministic fast path is used only for bounded intents. Ambiguous requests continue to model planning; benchmark latency does not represent model, browser, network, voice, camera, TTS, or full-workflow latency.
- Neural intent remains an accessibility and research interface. Synthetic and recorded EEG evidence does not establish live brain control, human accuracy, medical use, or unrestricted thought decoding.
- Local TTS isolation proves worker lifecycle and file synthesis on one developer machine. It does not establish audible quality, universal latency, or device compatibility.
- Camera, gaze, gesture, microphone, speaker, accessibility permissions, first-run setup, and other hardware-dependent paths still require validation on the user's actual devices.
- SignPath test-policy signing is validated. Production signing remains dependent on the production certificate becoming usable and the release workflow being migrated to it.
