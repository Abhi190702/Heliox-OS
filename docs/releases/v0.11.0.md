# Heliox OS v0.11.0 — Superseded Build Candidate

This tag passed source CI, but its stable GitHub release was not published because the Windows runner could not fetch WiX while creating the MSI. The same feature set is published as v0.11.1 with a checksum-verified, retryable WiX prefetch. Use v0.11.1.

This release combines the work completed after v0.9.0, including the v0.10.x source milestones and the later adaptive-intelligence, neural-research, multimodal, execution-reliability, and public-evidence work, into one installable version.

## Highlights

- **Continuous companion loop** — always-on voice, barge-in, spoken suggestions, risk interruption, browser control, and application control use one coordinated execution path.
- **Adaptive intelligence** — an append-only experience ledger, bounded temporal memory, verified online adaptation, strategy evolution, isolated candidate evaluation, and an optional JEPA-style predictor can improve planning without expanding permission.
- **21 specialists and 156 action types** — the capability-driven mesh reports concrete provider coverage for every declared action type, with runtime availability still constrained by operating system, credentials, installed tools, and policy.
- **Reliable gaze and gesture control** — gaze, 3D hand tracking, gesture workflows, and cursor mode share the camera while temporal verification rejects face-like and single-frame false positives.
- **Guarded neural research** — BrainFlow synthetic-board and recorded PhysioNet EEGBCI paths exercise signed, calibrated, consent-bounded intents. This is software and recorded-data evidence, not verified live brain control.
- **Durable work and truthful results** — persistent private sessions, resumable workflows, exact browser targeting, installed-application resolution, approval continuity, cancellation handling, and result verification reduce false success reports.
- **Moderated plugins** — reviewed marketplace packages use manifest, signature, SHA-256, and capability checks; catalog updates do not require a desktop release.
- **Cross-platform delivery** — first-run Chromium provisioning and Windows, macOS, and Linux packaging are part of the release workflow.
- **Public evidence and agent discovery** — generated capability, proof, release, citation, CodeMeta, `llms.txt`, MCP, and use-case surfaces make current behavior and limitations independently inspectable.

## Important boundaries

- Physical microphone, camera, gaze, and gesture accuracy varies by hardware and environment.
- Neural tests use synthetic or recorded EEG data unless a future release explicitly provides separate live-human evidence.
- Learned models may add caution or ranking; they cannot grant authority or suppress deterministic safety warnings.
- Only a subset of actions has an independent post-condition verifier. Executor success is not equivalent to independent proof for every external effect.
- Third-party websites, applications, APIs, models, and operating-system permissions can change outside Heliox.

## Upgrade

Download v0.11.1 or newer instead. Existing users should keep a settings backup, review changed permission prompts, and re-check microphone, camera, browser, credential-store, and optional-model configuration after installation.
